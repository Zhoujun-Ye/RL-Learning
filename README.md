# RL Learning

My personal learning journal for reinforcement learning, with a focus on mathematical foundations, derivations, and intuition.

These notes are a work in progress and may contain mistakes. I will revise them as my understanding develops.

## Notes

The notes are written in English using LaTeX. All content lives in [main.tex](main.tex).

## Build

Requires a TeX distribution such as TeX Live or MacTeX with XeLaTeX and `latexmk`. On macOS or Linux, run:

```sh
./compile.sh
```

The PDF is generated at `build/main.pdf`. Generated files are not tracked in Git.

For editing in VS Code, install **LaTeX Workshop** (`James-Yu.latex-workshop`) and open this repository as a folder. The included settings compile the notes on save. Use **LaTeX Workshop: View LaTeX PDF file** from the Command Palette to preview the PDF beside the source.
